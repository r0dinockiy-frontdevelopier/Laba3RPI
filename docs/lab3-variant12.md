# Лабораторная №3 — вариант 12

## Задача и решения

Добавить `useDebounce(value, delay)` на `useState` и `useEffect`; задержать поиск лекторов на 300 мс.
Хук возвращает отложенное значение, отменяет таймер при новом вводе и при размонтировании.

В исходном проекте нет поля поиска. Поэтому оно добавлено в блок «Наши лекторы».
В качестве минимального поведения выбран поиск по ФИО, без учёта регистра и пробелов по краям.
Очистка запроса использует ту же задержку и возвращает весь список.
Это допущения реализации, а не подтверждённые ответы автора.

## Проверка приёмочных критериев

- Хук принимает значение и задержку; возвращает отложенное значение.
- Быстрый ввод не вызывает фильтрацию для промежуточных значений.
- Через 300 мс после последнего ввода фильтрация выполняется один раз.
- Тест изменяет ввод несколько раз, проверяет отсутствие вызовов `filter` до истечения задержки и один вызов после неё.
- Проверены очистка поля, отсутствие совпадений и открытие карточки.
- Проверены отмена таймера при размонтировании и работа cleanup в StrictMode.

Команды проверки и сценарий демонстрации приведены в README.
